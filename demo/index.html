Firmatlas autocomplete

Type a Belgian company name or enterprise number. Pick a result and the form fills itself. Arrow keys, Enter and Escape work; so does a tap.

Declarative

Attributes only: data-kbo-autocomplete, a key, and a selector per field to fill.

Programmatic, in French

KboAutocomplete.attach(input, { key, lang: "fr", onSelect }) and the kbo:select event.
